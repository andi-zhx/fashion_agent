# AI Fashion Creator OS 产品说明

## 定位

AI Fashion Creator OS 是一个面向新锐服装创作者的轻量服装产品开发平台。它不是单点的服装效果图生成器，而是把市场机会、款式设计、面辅料、技术包、打样、生产、质检和销售复盘串成一个可执行工作流。

## 当前版本

当前版本采用 Python 标准库作为底层服务，前端通过浏览器访问。这样可以避免重量级安装，让项目先具备完整产品形态。

核心模块：

1. Product Brief：收集用户创意和商业约束。
2. Market：输出目标人群、渠道和小单验证策略。
3. Design：输出款式方向、颜色和 AI 图像提示词。
4. Materials：匹配面辅料、辅料、工厂和质检资源。
5. Tech Pack：生成规格表、尺寸表、工艺与包装要求。
6. Sampling：生成打样节奏和修改闭环。
7. Production & QC：生成生产排期、质检清单和交付风险。
8. Commerce：生成上架文案、素材方向和复盘指标。

## 大模型接口

`app.py` 中的 `call_model` 函数预留了 OpenAI-compatible Chat Completions 风格接口。通过 `config.local.json` 和环境变量即可替换为自己的模型服务。

未配置模型时，系统自动使用本地规则引擎，保证平台可以离线演示和持续开发。

## 推荐演进

- 第一阶段：继续完善规则引擎、资源库和技术包字段。
- 第二阶段：接入真实大模型，增强趋势分析、款式方案和销售素材。
- 第三阶段：接数据库，保存项目、BOM、打样记录、质检报告。
- 第四阶段：接供应链服务，形成面辅料询价、工厂排期、质检下单和订单追踪。
