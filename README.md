# AI Fashion Creator

面向新锐服装创作者的一站式 AI 服装产品开发协同平台 MVP。

这个版本把附件中的业务设想落成一个可运行的 Web 工作台，覆盖从市场机会识别、款式设计、面辅料匹配、产品资料包生成、打样协同、小单生产、第三方质检到销售复盘的完整链路。

## 当前功能

- 项目 Brief：输入品类、目标人群、风格、渠道、价格带、试产数量、季节、供应链区域和创意描述。
- AI 开发方案：基于规则引擎生成市场机会、设计方向、AI 图像提示词、BOM、尺寸表、工艺要求、打样流程、生产排期、质检计划和销售素材。
- 服装资源库：整合主面料、辅料、样衣工厂、生产工厂和第三方质检服务。
- 生产协同：展示从资料确认到出货质检的可执行时间线。
- 复盘看板：沉淀内容互动、预售转化、尺码反馈和返单信心等指标。
- 开发包导出：将当前项目导出为 JSON，后续可对接 ERP、PLM、供应商门户或数据库。

## 后续接入方向

- 接入真实大模型：把规则生成逻辑替换为趋势分析、款式生成、技术包生成和销售素材生成 API。
- 接入数据库：保存项目、BOM、供应商、打样记录、质检报告和销售复盘。
- 接入供应链接口：支持面辅料库存、打样报价、工厂排期、质检下单和物流状态。
- 增加权限与协作：创作者、平台商品开发、版师、工厂、质检机构分角色协同。
- 增加图片能力：生成款式效果图、平面款式图、AI 模特图和商品详情图。
